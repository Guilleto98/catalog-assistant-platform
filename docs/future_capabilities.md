# Capacidades fuera de V1

Quedan deliberadamente fuera: Google ADK, agente conversacional, LLMs, tools del agente, embeddings, RAG, agrupaciones, rankings, top productos, agregaciones complejas, alta/edición individual o masiva, preview/confirmación, fichas completas, comparación o clonación de fichas, PDFs, adjuntos, autenticación y autorización reales.

La V1 ofrece contratos determinísticos para que una fase posterior pueda envolverlos como tools sin mezclar lógica del catálogo con IA.
