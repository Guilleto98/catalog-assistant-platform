# Packages

Espacio para contratos, clientes generados, schemas y configuración compartida cuando exista una necesidad concreta.

[`contracts`](contracts/README.md) contiene modelos conceptuales de las etapas iniciales para Agent State, resultados de tools y eventos. No es una librería publicada ni la fuente de los contratos HTTP actuales. La fuente del contrato Application API es [`OpenAPI de Application API`](../docs/contracts/application-api-v1.openapi.json); el frontend genera sus tipos desde allí.
